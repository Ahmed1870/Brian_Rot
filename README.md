# Manzooma SQL — Lesson 21

Remotion/React educational video project: Scalar Subqueries in `SELECT` and `WHERE`.

- Composition: `Monzoma-SQL-L21`
- Output: `out/Lesson21_SQL-Scalar-Subqueries.mp4`
- 1920×1080 · 30 FPS · 240 seconds · 7200 frames
- Audio asset: `public/Manzooma_Store_Lesson_21_Scalar_Subqueries.mp3`

## Local setup

```bash
npm install
npm run typecheck
npm start
```

Render:

```bash
npm run render
```

This project uses a strictly 2D vector/UI approach. The numeric query-plan timing shown in Scene 05 is explicitly illustrative, not a benchmark claim.
