# PY-L05-VariablesTypes

Lesson 05 — Variables, Data Types & Type Conversion (Python course, Monzoma).
Remotion 4.0.250 · React 18.3.1 · TypeScript · **1920×1080 landscape (desktop)** · 30 FPS · 9000 frames (300 s).

- Voiceover: `public/voiceover_lesson_05.mp3` (supplied recording; 0:00–4:55 speech, last 5 s silent).
- SFX: `public/sfx_lesson_05.mp3` (synthesized by `scripts/gen_sfx.py`, silent after 4:55).
- Output: `out/py-l05-variablestypes.mp4` (rendered by GitHub Actions: `.github/workflows/render.yml`).
- Real code outputs: `scripts/run_examples.py` runs every sample with the real interpreter → `src/data/outputs.json`.
- Timing: `scripts/analyze_audio.py` → `src/data/timing.json` (scene boundaries snapped to real pauses; in-scene anchors are estimates).
- Visual events: `src/data/cues.ts` (single source for visuals and SFX).
