# Manzooma — Lesson 02: RDBMS Architecture
Remotion 2D vector video, 1920x1080 @30fps, 6750 frames (225 s). Composition ID: `BrainRotViral`.

    npm install
    npm start            # Remotion Studio preview
    npm run render       # generate-audio + render to out/BrainRotViral.mp4

Voiceover: `public/voiceover_lesson_02.mp3`. SFX/music are generated by `scripts/generate-audio.cjs` from `src/timeline.json`.
