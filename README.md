# PBI-L40-FilterAllRemoveFiltersAllExcept

Lesson 40 — FILTER وALL وREMOVEFILTERS وALLEXCEPT (Power BI course, unit 5: DAX basics).
Remotion 4.0.250 + React + TypeScript, 2D only. 1920×1080, 30 FPS, 9000 frames (300 s).

- Composition ID: `PBI-L40-FilterAllRemoveFiltersAllExcept` — output `out/pbi-l40-filterallremovefiltersallexcept.mp4`
- Voice-over: `public/voiceover_lesson_40.mp3` (measured 300.016 s). The last 5 s (frames 8850–8999) are silent, no SFX.
- All numbers on screen are computed in code (`src/lib/calc.ts`) from the lesson's Products/Sales data under a simulated filter context; Slicer clicks change the context and the affected visuals update.
- Scene timing: `src/timing.ts` is generated by aligning the script text to the audio's silence gaps (25 pauses). Anchors inside a scene are interpolated by text length (ESTIMATED, about ±2–3 s). Edit `SCENE_START_SEC` / `ANCHOR_SEC` to re-sync.
- Power BI Desktop (Report view) is a hand-drawn simulation, not pixel-exact.
- Font: the stack starts with `Cairo`, but Cairo is NOT bundled (unavailable when building); the bundled DejaVu Sans Condensed is used. To use Cairo: add the TTFs to `src/fonts` and an `@font-face{font-family:'Cairo'}` in `src/lib/fonts.tsx`.
- SFX are synthesized by `scripts/gen_sfx.py` (numpy), very low level.

Commands: see `TERMUX_COMMANDS.txt`. Deploy: `bash deploy.sh` (force-push to `main` of Brian_Rot; GitHub Actions renders).
